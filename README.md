# Aura Dent 🦷🤖

Plataforma web con agente conversacional para el agendamiento automatizado de citas odontológicas y confirmación mediante pasarela de pago.

Proyecto para el curso de **Ingeniería Web** (8vo Ciclo).

## 📁 Estructura del Proyecto

- `/backend` - API REST, lógica de citas y gestión de pagos.
- `/frontend` - Interfaz web (catálogo, widget del chatbot y panel administrativo).
- `/docs` - Diagramas UML, casos de uso y avances de documentación.

## 🌿 Flujo de Trabajo (Git)

- `main`: Versiones estables y entregas del curso.
- `develop`: Integración de características completadas.
- `feature/*`: Ramas de desarrollo individuales por tarea.
